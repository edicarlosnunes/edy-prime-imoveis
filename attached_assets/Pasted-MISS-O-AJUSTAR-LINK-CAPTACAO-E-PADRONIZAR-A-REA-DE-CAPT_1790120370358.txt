“Link para Proprietário”

“Link de captação”

Motivo:
Essa ferramenta não deve ser apresentada como exclusiva para proprietário. O LINK_CAPTACAO fará parte de um fluxo que poderá atender modalidades diferentes, portanto o nome correto da ferramenta é “Link de captação”.

`/admin/captacao/link`

4. TELA `/admin/captacao/link`

- Nome do proprietário
- WhatsApp
- botão “Gerar link exclusivo”

Essa não é a finalidade desejada.

Remover a obrigatoriedade de preencher nome e WhatsApp para gerar o link.

A função principal da tela deverá ser:

BOTÃO:
“Gerar link de captação”

Ao clicar:

1. gerar uma URL/chave exclusiva e segura;
2. apresentar o link gerado na própria tela;
3. disponibilizar um botão “Copiar link”;
4. permitir que o administrador copie esse link e envie posteriormente pelo canal que desejar.

O administrador NÃO deve precisar saber previamente quem vai utilizar o link.

5. FUNCIONAMENTO DO LINK

O link gerado deve continuar utilizando a estrutura segura já implementada para LINK_CAPTACAO:

- token aleatório;
- URL sem nome, telefone ou dados pessoais;
- somente hash do token persistido;
- token bruto não deve ser armazenado no banco;
- link deve abrir somente a ficha pública correspondente.

NÃO enfraquecer nem remover a proteção de token já implementada.

6. FICHA DE CAPTAÇÃO

NÃO modificar seus campos ou seu fluxo nesta missão.

NÃO transformar novamente o link em “link para proprietário”.

O objetivo agora é apenas garantir:

Gerar link → copiar link → abrir ficha existente.
